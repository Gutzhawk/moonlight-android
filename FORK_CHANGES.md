# Artemis Fork: меню геймпада и фоновая трансляция

Ветка `codex/controller-menu-background` основана на `moonlight-noir` проекта ClassicOldSong.

## Использование

- Нажмите L3 + R3 (оба стика) одновременно. Меню открывается один раз, пока оба стика не отпущены.
- Крестовина перемещает выбор, A подтверждает, B закрывает меню. Также работает сенсорный экран.
- В меню доступны возврат к трансляции, уход в фон, отключение клиента, завершение сессии на ПК с подтверждением и прежние дополнительные действия.
- Home и переключение приложений сохраняют текущее соединение. Вернуться можно через список последних приложений или уведомление.
- Разрешите уведомления, чтобы видеть кнопки возврата и отключения. Если уведомления запрещены, возвращайтесь через список последних приложений.
- «Отключиться» завершает подключение клиента; «Завершить сессию» также отправляет серверу команду закрытия приложения.

Сборка для проверки называется **Artemis Fork**, пакет `com.limelight.gutzhawk.debug`. Она устанавливается отдельно от оригинального Artemis; список компьютеров и настройки нужно настроить в ней заново.

## Как сохраняется сессия

Фоновая служба типа `mediaPlayback` удерживает процесс и CPU во время трансляции. При потере окна декодер переключается на отдельную EGL Surface, а при возвращении — на поверхность окна. `NvConnection` при этом не останавливается и повторное согласование соединения не запускается. Фоновые видеокадры продолжают декодироваться и отбрасываются без ожидания экранного VSYNC. Звук продолжает воспроизводиться.

Требуется Android 6.0+ и поддержка `MediaCodec.setOutputSurface` видеодекодером. Если декодер отклоняет переключение, приложение сообщает об этом и штатно завершает подключение. Принудительная остановка, удаление задачи из списка последних приложений, потеря сети и завершение процесса системой прекращают сессию. Исключения из энергосбережения Samsung автоматически не меняются.

## Сборка и проверка

Нужны JDK 17 или 21, Android SDK 36 и NDK 27.0.12077973.

```text
git submodule update --init --recursive
gradlew :app:testNonRoot_gameDebugUnitTest --tests "*ControllerMenu*Test" --tests "*GameBackgroundTest" --tests "*StreamSessionServiceTest" --tests "*GameMenuControllerTest" --tests "*DecoderSurfaceSwitchTest"
gradlew :app:assembleNonRoot_gameDebug
```

Для Samsung M17 предназначен APK `arm64-v8a`. На Windows NDK требует путь без пробелов: можно временно назначить папке диск через `subst` и запускать Gradle с него.

Проверки охватывают повторное нажатие и отпускание стиков, блокировку игрового ввода при открытом меню, управление меню геймпадом, сохранение соединения при сворачивании, перенаправление поверхности декодера, уведомление, явное отключение и освобождение ресурсов.

Проверка на физическом телефоне не проводилась. После установки проверить: L3 + R3 → меню → возврат; Home → 30 секунд в другом приложении → возврат без подключения; блокировка и разблокировка экрана; отключение через уведомление; завершение сессии с подтверждением. Обычное сворачивание и принудительное закрытие приложения — разные действия.

Полная проверка Android Lint обнаруживает существующие ошибки исходного проекта в `StreamSettings`, `AppView`, `PcView`, проверках API датчиков геймпада и вьетнамской строке форматирования. Они не отключены и не исправляются этой веткой.
